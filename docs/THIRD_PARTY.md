These are shipped inside the repository. **Licences are quoted from memory of the upstream projects – verify them before you distribute the game.** Where a licence file is part of the repository it is named.

| Component | Location | Author / source | Licence |
|---|---|---|---|

| uRaymarching | `Assets/uRaymarching` | hecomi – <https://github.com/hecomi/uRaymarching> | MIT upstream (licence file not included in this copy) |
